# ⚡ رادار قنص الذعر اللحظي — Panic Sniper Terminal V2

مراقبة لحظية **كل 15 دقيقة** للأسهم الأمريكية منخفضة الفلوت التي
**هبطت ≥ 30% من قمة اليوم ← ثبّتت أفقيًا قرب قاعها ← بدأت مؤشرات الزخم بالانعكاس.**

نظام مبني على فكرة ومنطق «قنص الذعر» في `stouk-bot`، بنفس شروطه الأصلية حرفيًا،
مع طبقات تحليل إضافية وداشبورد طرفية داكن بأسلوب برامج التداول الاحترافية.

> **ورقي بالكامل** — لا تنفيذ أوامر، ولا توصية استثمارية، ولا إدارة محافظ.

**الداشبورد:** <https://omermasaad.github.io/reverse-split-radar/>

## ما الذي يفعله النظام

| | |
|---|---|
| 🌐 **الكون** | يبني يوميًا قائمة أسهم منخفضة الفلوت: السعر $0.50–$10 · Float < 5M · متوسط حجم ≥ 100k |
| 📡 **المسح** | كل **15 دقيقة** خلال ساعات التداول الأمريكي (08:00–21:45 UTC) |
| 🚀 **الرجل الأولى** | لا يُرصد سهم لم يصعد أولًا ≥ **100%** من قاع ما قبل القمة، وبحجم ≥ **1.5×** خط الأساس — الصعود هو مصدر الطاقة |
| 📉 **الإشارة** | هبوط **30%–50%** من القمة (الأعمق يخرج `too_deep`) + ثبات أفقي ≥ 60 دقيقة قرب قاع الانهيار + RSI بدأ يتحسن + OBV شرائي + زخم MACD |
| 🧹 **التنظيف الآلي** | كسر قاع الثبات بـ −5% ⇒ شطب نهائي من جلسة اليوم |
| 🔬 **تحليل إضافي** | تأكيد فريم 15m · VWAP مرتكز · دلتا الحجم · جفاف حجم القاعدة · جودة القاعدة · ATR · خريطة مستويات · دوران الفلوت |
| ⚖️ **محرك مخاطرة** | الوقف **قاع الثبات − 5%** (أو ATR إن أوسع) · هدفان **+20% و+30%** · **VWAP سقف مقاوم** تُقيَّد الأهداف قبله إذا كان السعر تحته · وضعَا دخول (فوري أعلى القاع / اختراق قمة القاعدة) · عائد/مخاطرة · حجم مركز ورقي |
| 📊 **قياس الأداء** | رصد ورقي لكل إشارة: MFE/MAE · تحقق الأهداف · نسبة النجاح · Profit Factor · توزيعات حسب الدرجة والساعة وعمق الهبوط |

## الداشبورد

واجهة عربية (RTL) داكنة، تعمل كملف واحد بلا أي اعتماديات خارجية (بلا CDN):

- **شريط علوي حي:** ساعة نيويورك، مرحلة الجلسة، عدّاد المسح القادم، تحديث تلقائي كل 60 ثانية.
- **شريط أسعار متحرك** بكل الأسهم المرصودة.
- **بطاقات KPI** + **قمع المسح** من الكون إلى الإشارة المكتملة.
- **جدول رادار** قابل للفرز والبحث والتصفية (حالة، درجة، مكتملة فقط، تجزئة عكسية) مع تصدير CSV.
- **درج تفاصيل** لكل سهم: رسم شموع 5m مع منطقة الثبات والوقف والأهداف وVWAP وEMA9،
  ولوحات RSI/MACD/OBV/الحجم، وقائمة الشروط، وخطة المخاطرة، وخريطة المستويات،
  وجودة القاعدة، والحجم والتدفق، وتأكيد الفريم الأعلى، ومسار الإشارة.
- **تبويب الأداء الورقي** و**تبويب الشروط** (يُبنى من بيانات المحرك نفسه) و**تبويب سجل التشغيل**.
- اختصارات: `/` للبحث · `Esc` للإغلاق · `↑ ↓` للتنقل بين الأسهم.

## التشغيل محليًا

```bash
pip install -r requirements.txt

# 1) بناء كون الأسهم منخفضة الفلوت (مرة يوميًا)
python build_universe.py                 # أو --limit 300 للتجربة

# 2) مسح واحد
python panic_sniper.py                   # أو --tickers MULN,NCI أو --limit 50

# 3) فتح الداشبورد
python -m http.server 8000               # ثم http://localhost:8000
```

**للعرض بدون انتظار السوق:**

```bash
python tools/make_demo.py                # يولّد بيانات عبر محرك المسح نفسه
node tools/verify_dashboard.mjs          # فحص الواجهة (يحتاج: npm i --no-save jsdom)
python tests/test_sniper.py              # 36 اختبارًا بلا إنترنت
```

## الجدولة على GitHub Actions

| الملف | الوظيفة | التكرار |
|---|---|---|
| `.github/workflows/panic_sniper.yml` | مسح قنص الذعر ورفع البيانات | `*/15 8-21 * * 1-5` |
| `.github/workflows/universe_build.yml` | بناء الكون | `20 12 * * 1-5` |
| `.github/workflows/ci.yml` | اختبارات المحرك + فحص الداشبورد | عند كل Push/PR |

كل مسح: اختبارات ← مسح ← تحقق من المخرجات ← commit مع إعادة محاولة `pull --rebase`.
الوظيفة محددة بـ `timeout-minutes: 20` و`concurrency` مع إلغاء التشغيل السابق،
حتى لا تتراكم المهام ولا يتوقف الجدول.

**متغير اختياري:** `Settings ▸ Variables ▸ SEC_CONTACT` = بريدك (مطلوب من SEC EDGAR).

## النظام القديم

نظام «رادار التجزئة العكسية اليومي» (V1.0) **معطَّل بالكامل**: نُقلت جدولاته
وسكانره وبياناته إلى [`archive/disabled/`](archive/disabled/README_AR.md) بدل حذفها.
توقفت كل مهامه المجدولة تلقائيًا، ويمكن استعادته بأمر `git mv` واحد لكل ملف.

## الاختبار

```bash
python tests/test_sniper.py     # 46/46 — البوابات، الشروط، VWAP، الشطب، الحالات، المتتبّع، الكون، الـ JSON
node tools/verify_dashboard.mjs # 45 فحصًا في DOM حقيقي (jsdom)
```

الاختبارات تعمل على بيانات 5m اصطناعية بلا إنترنت، وتمرّ على **نفس دوال المحرك**
(`evaluate`, `merge`, `update_stats`, `run_once`) لا على نسخ بديلة منها.

## إخلاء مسؤولية

نظام مراقبة تجريبي لأغراض البحث والقياس. البيانات من Yahoo Finance وقد تكون متأخرة
أو ناقصة. كل الإشارات **ورقية**: لا انزلاق سعري ولا عمولات ولا تأثير على السيولة.
لا ينفّذ أوامر ولا يقدّم توصية استثمارية.
